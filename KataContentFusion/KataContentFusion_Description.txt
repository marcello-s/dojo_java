ContentFusion is a content creation tool based on media data.
The tool analyses volumes of movie and tv-show content.
It then creates new content based on data it found.

dependencies: MySQL Driver

movies archive
--------------

Volumes contain a folder /Movies:

/[<Collection>]
    /<title> (<year>) [<language>,<language>]
        /media file
        /media file
/<title> (<year>) [<language>,<language>]
    /media file
    /media file

Within the folder are either collections of movies, or just movies.
The folder contains name key information, and the folder contains media files.


www.themovie.org API
--------------------

help for consuming a REST API
https://spring.io/guides/gs/consuming-rest

Enrich movie information by consuming an online service. 
Search for the movie by title and year. Load movie details and credits.

The RestClient needs a Bearer token.
Set env variable: THEMOVIEDB_API_BEARER_TOKEN
