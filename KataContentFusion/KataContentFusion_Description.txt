ContentFusion is a content creation tool based on media data.
The tool analyses volumes of movie and tv-show content.
It then creates new content based on data it found.

dependencies: MySQL Driver
https://start.spring.io/

https://spring.io/guides

gradle
show all tasks
$ .\gradlew.bat -q :tasks --all

build
$ .\gradlew.bat build

run
$ .\gradlew.bat bootRun --args="scan movies volume-name C:\temp\_cf\Movies"
$ .\gradlew.bat bootRun --args="import movies C:\temp\_cf\scannedMovies.json"
$ .\gradlew.bat bootRun --args="enrich movies 3"
$ .\gradlew.bat bootRun --args="blah blah blah blah"


movies archive
--------------

Volumes contain a folder /Movies:

/[<Collection>]
    /<title> (<year>) [<language>,<language>]
        /media file
        /media file
/<title> (<year>) [<language>,<language>]
    /media file
    /media file

Within the folder are either collections of movies, or just movies.
The folder contains name key information, and the folder contains media files.


www.themovie.org API
--------------------

help for consuming a REST API
https://spring.io/guides/gs/consuming-rest

Enrich movie information by consuming an online service. 
Search for the movie by title and year. Load movie details and credits.

The RestClient needs a Bearer token.
Set env variable: THEMOVIEDB_API_BEARER_TOKEN

local database
--------------

For a local integration of all extracted data ContentFusion can use an in-memory database.
SQLite contains a few tables to import scanning results and information from themoviedb.org.
download sqlite tools
https://sqlite.org/download.html
(add to path, and test> sqlite3 -version)

DB Browser for SQLite, UI tool
https://sqlitebrowser.org/

command line parameter
--enable-native-access=ALL-UNNAMED
set 'hibernate.transaction.jta.platform=enable'

db scripts in: /src/main/resources (schema.sql, data.sql)
application.properties: needs lots of entries
# this will nor enforce ugly snake_case for tables/columns
spring.jpa.hibernate.naming.physical-strategy=org.hibernate.boot.model.naming.PhysicalNamingStrategyStandardImpl
